## ML task
### Метрики 
При анализе данных был сделан вывод о наличии дисбаланса классов: 75% <=N vs 25% >N.
Исходя из этого, метрика `Accuracy` не будет отображать объективную оценку качества модели.
Поэтому, наиболее репрезентативными метриками будут являться `ROC-AUC` и `F1-score`:
- `ROC-AUC` оценивает качество модели в целом независимо от порога классификации
- `F1-score` является балансом между метриками `Precision` и `Recall`
